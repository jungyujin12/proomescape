# 따라 하기

## 1. 빈 스프레드시트 만들기

Google 스프레드시트에서 **빈 스프레드시트**를 하나 만드세요.

주소가 아래처럼 보입니다.

`https://docs.google.com/spreadsheets/d/긴문자열/edit`

`/d/`와 `/edit` 사이의 긴 문자열을 복사하세요.

## 2. Apps Script 열기

스프레드시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누르세요.

화면에 있는 기존 코드를 모두 지우고 프로젝트의 `apps-script/Code.gs` 내용을 전부 붙여넣으세요.

## 3. 코드 위쪽 두 줄 수정하기

다음 부분에 복사한 스프레드시트 ID와 원하는 관리자 비밀번호를 입력하세요.

```javascript
const INITIAL_SPREADSHEET_ID = '복사한 ID';
const INITIAL_ADMIN_PASSWORD = '원하는 8자 이상 비밀번호';
```

## 4. 자동 설정 실행하기

위쪽 함수 선택 메뉴에서 `initialSetup`을 선택하고 **실행**을 누르세요. Google 권한 확인 화면이 나오면 본인 계정으로 허용하세요.

## 5. 웹 앱으로 배포하기

오른쪽 위 **배포 → 새 배포 → 유형 선택 → 웹 앱**을 누르세요.

- 다음 사용자로 실행: **나**
- 액세스 권한: **모든 사용자**

**배포**를 누르면 마지막에 `/exec`로 끝나는 웹 앱 주소가 나옵니다. 이 주소만 Codex에게 보내주세요.

스프레드시트 ID나 관리자 비밀번호는 보내지 않아도 됩니다.
