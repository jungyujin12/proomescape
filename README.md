# 방탈출 부스 접수·관리 페이지

## 기능

- 이름·전화번호 필수 접수
- 학번·학과·학년 선택 입력
- 개인정보 및 안전수칙 서명
- 월요일 오후부터 금요일 오전까지 15분 간격 예약
- 관리자 날짜·상태 필터, 검색, 상태 변경, 서명 확인, CSV 다운로드
- PC·모바일 반응형 화면

## Google 스프레드시트 온라인 연결

무료 Google Apps Script를 사용하면 모든 휴대폰과 PC에서 같은 예약 목록을 공유할 수 있습니다.

1. [apps-script/설치방법.md](apps-script/설치방법.md)의 순서대로 Apps Script를 설정합니다.
2. 발급받은 `/exec` 주소를 `sheets-config.js`에 입력합니다.
3. 사이트를 무료 정적 호스팅에 올립니다.

Apps Script 주소가 비어 있으면 화면 미리보기를 위해 현재 브라우저에 저장됩니다. 주소가 설정되면 Google 스프레드시트 온라인 저장 방식으로 자동 전환됩니다.

운영 시간은 `app.js` 상단의 `OPERATING_HOURS`에서 변경할 수 있습니다.
